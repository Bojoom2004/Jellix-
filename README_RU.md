# Jellix core — этап 3

Переносимое ядро лаунчера на C99. На устройстве нужны только memset/memcpy/strlen.
Экран, кнопки, файлы и звук делает слой HAL (пока не написан).

## Этап 1 — логика
- `core/jx_cfg.c` — настройки key=value (мусор и значения вне диапазона игнорируются)
- `core/jx_input.c` — ремап, турбо, перестановка L/R, правило Vol+/Vol−, звуки интерфейса
  только в лаунчере/паузе, индикатор громкости
- `core/jx_thumb.c` — миниатюры сохранений JTH1
- `core/jx_catalog.c` — каталог игр без динамической памяти: поиск, сортировка, избранное/скрытие, статистика запусков
- `core/jx_log.c` — кольцевой журнал событий (32 × 72 байта)
- `core/jx_profile.c` — профили платформ: индивидуальный ремап, Turbo, масштабирование, фильтр и перемотка; caller-owned storage

## Этап 2 — отрисовка и главный экран
- `tools/png2jxi.py` — PNG → `.jxi` (RGB565 + 8-бит альфа, только если нужна), BMFont → `.jxf`.
  Весь набор ассетов 480×320 = ~0.9 МБ (готов к показу без декодера PNG)
- `core/jx_gfx.c` — заливка, блит с отсечением и альфой, текст UTF-8 (кириллица), без malloc и без div
- `core/jx_home.c` — сетка 5×4, перемещение выбора с краями и неполной последней строкой
- `sim/sim_main.c` — ПК-симулятор: читает ресурсы как устройство, рисует главный экран в PPM
- `sim/sim_text.c` — проверка шрифтов на латинице и кириллице

## Команды
    python3 tools/png2jxi.py dir <assets_480x320> build/assets
    python3 tools/png2jxi.py font <jlx_font_h16.fnt> build/assets/font_h16.jxf
    make test    # 137 проверок, с ASan/UBSan
    make sim && /tmp/jx_sim build/assets 1 out.ppm
    make mips    # компиляция под mips32r2 little-endian (clang), ядро ~10 КБ кода

## Проверено
- Главный экран совпадает с эталонным макетом: отличаются 439 из 153 600 пикселей, все вокруг
  рамки подсветки выбранной плитки (она нарисована в макете чуть иначе). Плитки совпадают точно.
- В первой версии шрифта у букв была тёмная обводка, из-за чего «G» читалась как «O».
  Нашлось визуальной проверкой, исправлено в конвертере.
- Родной компилятор sde-gcc в облаке не запускается (нет 32-битных библиотек).
  Сборка под ActSDK ещё не проверена.

## Проверено на этапе 3
- `make test`: 137/137 проверок успешно (ASan/UBSan).
- `make mips`: все модули компилируются Clang под mipsel / MIPS32r2 freestanding. Это объектная проверка, не native SDE/ActSDK build и не готовый `.app`.
- ATS3603 подтверждён владельцем консоли по маркировке микросхемы после разборки. Разрешение/модель LCD и ревизию платы всё ещё нужно подтвердить.
